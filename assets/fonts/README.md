# Fontes locais

Sora, Roboto, Noto Sans Symbols e Noto Emoji, incluídas para renderizar texto, símbolos e emojis sem buscar fontes externas.

Fonte oficial: google/fonts, commit `bd8f81ddb5c74d5c8897b36ad88b440266245103`.
Diretórios de origem: `ofl/sora`, `ofl/notosanssymbols`, `ofl/notoemoji`, `ofl/roboto`. Roboto também está registrada localmente como fonte padrão do engine Web.
Licenças SIL Open Font License 1.1 incluídas nos arquivos `OFL-*.txt`, também empacotadas como assets.
